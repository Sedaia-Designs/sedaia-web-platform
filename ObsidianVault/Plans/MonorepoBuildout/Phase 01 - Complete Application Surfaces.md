# Phase 01 - Complete Application Surfaces

**Status: Pending requirements.**

1. Define the minimum useful scope for documentation and blog sites.
2. Create `apps/docs` and `apps/blog` only after their framework and content
   workflow requirements are selected.
3. Give each application isolated build, lint, test, local-run, and Vercel
   configuration where applicable.
4. Add root commands and path-filtered CI without coupling unrelated apps.

Exit criterion: every committed application surface builds independently and
has an identified deployment owner.
