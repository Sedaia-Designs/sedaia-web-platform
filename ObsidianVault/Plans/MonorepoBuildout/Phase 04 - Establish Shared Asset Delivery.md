# Phase 04 - Establish Shared Asset Delivery

**Status: Deferred until the first shared-asset use case.**

1. Identify an asset required by more than one application.
2. Select object storage or a Vercel-compatible CDN using concrete retention,
   cache, cost, and publication requirements.
3. Use immutable versioned or content-hashed paths and long-lived cache
   headers.
4. Document publication, invalidation, ownership, and recovery.

Exit criterion: shared assets have a reproducible publication path without
moving application-specific assets unnecessarily.
